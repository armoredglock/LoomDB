# LoomDB Social Share Copy

LoomDB is a forkable, deterministic, budget-enforced, zero-copy embedded multi-modal database with a stable single-file ABI and native OPFS multi-tab coordination.

Built in pure safe Rust with sub-512KB idle RAM overhead.
Eliminate database sprawl: ANSI SQL, JSON documents, AVX-512 vector search, and time-series streams inside a single portable `.loom` container.

Check it out on GitHub:
https://github.com/armoredglock/LoomDB
