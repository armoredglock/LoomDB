# LoomDB Launch Video Plan (/brag-slim)

## 1. Project Profile & Angle
* **Product:** LoomDB &mdash; The World's Lightest Multi-Modal Database.
* **Core Value Proposition:** 5 database paradigms (SQL, JSON, Vectors, Time-Series, Graph) woven into a single portable `.loom` container file with sub-512KB idle RAM overhead.
* **Target Audience:** Developers building local AI agents, desktop apps (Tauri/Electron), microservices, edge devices, and anyone tired of running 4 heavy Docker containers for simple projects.
* **Tone:** `polished` &middot; Punchy, high-craft systems engineering, confident, razor-sharp pacing.
* **Format:** Landscape (1920x1080), 30 fps, exactly 20.0 seconds (600 frames).
* **Music Tempo:** 120 BPM (0.5s per beat, 15 frames per beat). Every scene cut aligns strictly with a downbeat.
