# Security Policy

## Supported Versions

LoomDB security patches are released for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of LoomDB seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please send an advisory email to:
`security@loomdb.dev`

Please include:
* A description of the vulnerability and its potential impact.
* Detailed steps or a minimal proof of concept to reproduce the issue.
* The operating system, architecture, and LoomDB version used.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible disclosure and patch release.
